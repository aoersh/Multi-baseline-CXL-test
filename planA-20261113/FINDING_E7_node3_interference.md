# E7：在 node3 上重复干扰域分解（2026-11-20）

## 目的

§4.3 的干扰域分解（"同设备竞争比跨 socket 贵 6.4–8.0×"）只在 node2 上做过，
论文因此无法主张该效应与链路速率无关。本实验在 node3 上做镜像对照。

## 方法

E3 的镜像，全部搬到 socket 1：

| | E3 (node2, socket 0) | E7 (node3, socket 1) |
|---|---|---|
| 本地探针 | CPU 0 | CPU 16 |
| 跨路探针 | CPU 16 | CPU 0 |
| 负载核 | 1–4 | 17–20 |
| 负载 → 另一设备 | node0 (DRAM) | node1 (DRAM) |
| 负载 → 被测设备 | node2 | node3 |

K=1 与 K=8，各 3 次重复。数据：`runs/e7-20261120-173436/results.csv`

## 结果

### node2 (Gen4, socket 0) —— E3

| K | 同设备效应（本地探针） | 同设备效应（跨路探针） | 跨 socket 代价 | 比值 |
|---:|---:|---:|---:|---:|
| 1 | +812.1 ns | +655.5 ns | +102.0 ns | **8.0× / 6.4×** |
| 8 | +110.3 ns | +125.9 ns | +33.5 ns | 3.3× / 3.8× |

### node3 (Gen5, socket 1) —— E7

| K | 同设备效应（本地探针） | 同设备效应（跨路探针） | 跨 socket 代价 | 比值 |
|---:|---:|---:|---:|---:|
| 1 | +364.9 ns | +246.4 ns | +244.7 ns | **1.5× / 1.0×** |
| 8 | +39.9 ns | +45.9 ns | +58.3 ns | **0.7× / 0.8×** |

## 结论：比值不复现

**同设备竞争确实存在，且在两块设备上都为正**（+365 ns 和 +246 ns，K=1）。
但它相对跨 socket 代价的**倍数不复现**：

- node2，K=1：6.4–8.0×
- node3，K=1：1.0–1.5×
- node2，K=8：3.3–3.8×
- node3，K=8：**0.7–0.8×**（比值反转，跨 socket 反而更贵）

原因在分母：跨 socket 代价在两块设备上差 2.4 倍（102 vs 245 ns，K=1），
而分子也差 2.2 倍（812 vs 365 ns）。两者不同步，比值因此不恒定。

## 对论文的影响

**贡献 #3 必须大幅收窄。**

原表述"干扰域而非 NUMA 距离，同设备竞争贵 6.4–8.0×"是把 node2 的单点结果
当成了普遍规律。正确表述应为：

> 干扰域的代价是真实的，且在两块设备上都存在；但它相对跨 socket 代价的
> 倍数高度依赖具体设备与 socket 组合（1.0× 到 8.0×），不能作为可推广的
> 定量主张。在 node3 上，K=8 时跨 socket 代价甚至超过同设备竞争。

这条负面结果削弱了论文的一个卖点，但它是实测的，必须如实写入。
继续按原样保留 6.4–8.0× 会构成选择性报告。
